일반화한다. 단순 작업과 팀 작업의 구분을 파일 수나 단계 수가 아니라, 독립된
역할 분리와 교차 검증의 실익을 기준으로 보완한다. 여러 활성 플랜은 서로 다른
브랜치 또는 worktree로 격리된 경우 허용하고, 같은 작업 트리에서 동시에 쓰지
않도록 안전 조건을 명시한다.
