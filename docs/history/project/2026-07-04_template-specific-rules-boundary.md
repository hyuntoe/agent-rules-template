# 템플릿 전용 규칙 경계 정리

## Plan

프로젝트별로만 의미가 있는 작업 규칙을 공통 템플릿 문서에 섞지 않도록 README와 docs 워크플로우에 짧은 기준을 추가한다. 이 템플릿은 다른 프로젝트에 다시 병합될 수 있으므로, 공통 규칙과 프로젝트 고유 규칙의 경계를 명확히 둔다.

## Context Notes

- 상태: active.
- 작업 브랜치: 현재 브랜치.
- 사용자 원문은 그대로 쓰지 않고, 재병합 가능성을 이유로 프로젝트 고유 규칙을 공통 템플릿 문서에서 분리한다는 취지로 다듬어 반영한다.

- `git diff`로 README와 workflow 규칙의 추가 문구만 반영된 것을 확인했다.
