# 다음 작업

## 개인 프로젝트 10개에 공통 에이전트 규칙 추가 병합

`agent-rules-template`을 기준 원본으로 삼아 현재 개인 프로젝트 목록 10개의
에이전트 진입 규칙, 공통 개발 규칙, docs 워크플로우, 멀티에이전트 규칙,
로컬 컨텍스트 라우팅 규칙과 공통 스킬을 점검하고 추가 병합 적용한다.

### 대상

- WSL
  - `ai-hq`
  - `jk-exam-kb`
  - `jk-math`
  - `rabbit7-trader`
  - `rabbit7-wiki`
- Windows
  - `agent-rules-template`
  - `jk-japanese`
  - `jk-make-mathtest`
  - `jk-manager`
  - `SCS Mod modding`

`agent-rules-template` 자체에는 내용을 다시 병합하지 않고 배포 기준 원본의
상태와 문서 간 참조 무결성만 확인한다. 나머지 9개 프로젝트에는 각 프로젝트의
기존 규칙과 고유 문맥을 먼저 읽은 뒤 필요한 내용을 추가 병합한다.

### 적용 원칙

- 템플릿 파일로 대상 프로젝트의 문서를 통째로 덮어쓰지 않는다.
- 프로젝트 고유 규칙과 기존 결정은 보존하고 공통 규칙과 충돌하는 부분을 먼저 식별한다.
- 각 프로젝트에서 적용 범위와 제외 근거를 기록한다.
- 비단순 병합은 해당 프로젝트의 격리 브랜치와 worktree에서 진행한다.
- 프로젝트별로 문서 참조, 스킬 경로, 테스트 또는 검증 명령을 확인한다.
- 프로젝트 하나의 적용과 검증이 끝날 때마다 별도 의미 단위로 커밋한다.
- 원격 푸시는 해당 프로젝트의 배포 필요성과 사용자 승인을 확인한 뒤 수행한다.

### 완료 조건

- [ ] 기준 원본 `agent-rules-template`의 상태와 참조 무결성을 확인한다.
- [ ] 나머지 9개 프로젝트의 기존 규칙과 템플릿 차이를 각각 검토한다.
- [ ] 각 프로젝트에 필요한 공통 내용을 충돌 없이 추가 병합한다.
- [ ] 각 프로젝트에서 문서 링크, 경로와 적용 결과를 검증한다.
- [ ] 프로젝트별 적용 내역과 의도적으로 제외한 항목을 기록한다.
